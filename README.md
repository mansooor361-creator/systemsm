# DaAIx Desktop — منصة قواعد المعرفة القانونية | Legal Knowledge Base Desktop

تطبيق ديسكتوب (Windows / macOS / Linux) مبني على Electron، مرتبط بموقع [smartk-ai.com](https://smartk-ai.com/) — واجهة بأسلوب Obsidian مبنية على قواعد معرفة قانونية جاهزة (وليس ملاحظات يبنيها المستخدم من الصفر)، مع دردشة مُسنَدة 100% إلى قاعدة المعرفة بدون هلوسة.

A desktop app (Windows / macOS / Linux) built on Electron for [smartk-ai.com](https://smartk-ai.com/) — an Obsidian-style workspace grounded in pre-built legal knowledge bases, with a 100% grounded chat (no hallucination).

---

## المزايا | Features

### قواعد المعرفة | Knowledge Bases
- تنزيل قواعد المعرفة وتحديثها المستمر عبر Manifest من الخادم + إشعارات تلقائية (`main/updater.js`)
- أنواع وثائق مخصصة لكل منها طريقة عرض: **نظام، لائحة، قرار، اتفاقية، حكم قضائي، مبدأ قضائي، تعميم**
- **سجل إصدار** كامل لكل وثيقة (الإصدار، التاريخ، التعديل، أداة التعديل)
- **الارتباطات**: يعدل / معدل بـ / يستند إلى / مستند إليه / اللائحة التنفيذية — بروابط عائدة (Backlinks)
- في الأحكام: **المستند عليه في نص الحكم** (المواد والأنظمة) يظهر تلقائياً
- خريطة ارتباطات تفاعلية (Graph View) مرسومة على Canvas بدون أي مكتبات خارجية
- بحث فوري ثنائي اللغة (عربي/إنجليزي) في كل النصوص

### الدردشة المُسنَدة | Grounded Chat
- **وضع الاستخلاص المحلي (افتراضي):** الإجابات مقتطفات حرفية من قاعدة المعرفة مع استشهادات مرقّمة قابلة للنقر — استحالة تقنياً للهلوسة
- **وضع الذكاء الاصطناعي (اختياري):** أي خدمة متوافقة مع OpenAI API، بدرجة حرارة صفر وتعليمات صارمة: الإجابة فقط من المقاطع المسترجعة، والامتناع عن الإجابة إن لم توجد في قاعدة المعرفة
- نطاق الإجابة: كل القواعد، أو الوثيقة الحالية وارتباطاتها فقط

### الأدوات | Tools (8)
1. المستشار الرقمي القانوني (مُسنَد لقاعدة المعرفة)
2. التحويل إلى Markdown (PDF / Word DOCX / HTML / TXT) + استيراد مباشر إلى الملاحظات
3. حاسبة التكاليف القضائية (مطالبات 5% / تنفيذ 2% / استئناف)
4. الحاسبة العمالية (مكافأة نهاية الخدمة وفق المواد 74/76/84 من نظام العمل + مدة الإخطار)
5. المستشار العمالي (نطاق: النظام + اللائحة التنفيذية + الأحكام)
6. مستشار أنظمة المنافسات
7. تقديم العروض ودراستها (هامش الربح، الدرجة، احتمالية الفوز)
8. الاشتراطات للبناء (قائمة التزام لكل مرحلة مع نسبة الإنجاز)

### أخرى | More
- واجهة عربية/إنجليزية كاملة مع RTL/LTR فوري
- مظهر داكن/فاتح بأسلوب Obsidian
- قسم «ملاحظاتي» الخاص بالمستخدم (Markdown، محفوظ محلياً)
- إعدادات محفوظة محلياً، لا تُرسل أي بيانات إلا عند تفعيل خدمة الذكاء الاصطناعي

```bash

```

## ربط التحديثات مع الموقع | Server-side updates

يجعل التطبيق الاستعلام دورياً عن `updateUrl` (قابل للتعديل من الإعدادات). المتوقع JSON:

```json
{
  "kb": [
    { "id": "kb-sa-legal", "version": "2025.2.1", "url": "https://smartk-ai.com/api/kb/kb-sa-legal.json" }
  ]
}
```

عند تغيّر `version` يظهر إشعار في التطبيق وإشعار نظام، ويمكن تنزيل القاعدة عبر `kb:fetchRemote` ثم `kb:saveDownloaded`.

## البنية | Structure

```
main/          Electron main process (نافذة، تخزين، تحويل ملفات، تحديثات)
renderer/
  js/kb.js         فهرسة قواعد المعرفة والبحث ثنائي اللغة
  js/retrieval.js  محرك الاسترجاع المُسنَد (بدون هلوسة) + وضع LLM اختياري
  js/calculators.js الحاسبات القانونية
  js/graph.js      خريطة الارتباطات (Canvas)
  js/tools.js      الأدوات الثمانية
  js/app.js        المتحكم الرئيسي (الشجرة، العارض، سجل الإصدار، الارتباطات)
  data/kb-sample.json  قاعدتا معرفة نموذجيتان (سعودي قانوني + مذاهب فقهية)
tests/         اختبارات منطق + اختبارات DOM كاملة
build/         أيقونات التطبيق
```
